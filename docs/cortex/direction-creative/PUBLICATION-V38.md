# Cervonaute v3.8 — direction créative V2

Publication demandée explicitement le 17 novembre 2026 après validation de la recherche visuelle V2. Le site adopte les neuf paysages (premier jardin conservé, régions 2 à 9 en V2), une interface claire indigo/menthe/pêche, des panneaux colorés et une typographie sans empattements. Accents et fond évoluent selon l’arène. Connexion, accueil, étude, exploration, labo et carnet harmonisés. Le laboratoire utilise l’intérieur des archives comme décor.

Les 24 cartes, leurs illustrations, le catalogue, les insignes, le logo, les règles de progression et Supabase sont conservés. Les animations restent différées. Le coffre actuel demeure en attendant la passe dédiée. Les simulations sont réservées à `?apercu=1` ; aucune simulation n’est activée par le nouveau thème.

Vérification locale Edge : connexion réelle sans session (aucun e-mail envoyé), neuf scènes/palettes, contraste blanc sur objectif supérieur à 4,5:1, six écrans du parcours sur données fictives, largeurs 320/390/768/1440 px, images décodées, aucune erreur JavaScript ni ressource manquante, aucun appel Supabase. Les ressources du cache hors ligne sont présentes. Les captures ont été inspectées. Tests : `tools/verifier_cortex_creatif.cjs` ; vérification publique après publication : `tools/verifier_publication_cortex_v38.cjs`.

Les recherches V1 et les sources PNG restent locales ; seuls les neuf exports WebP retenus sont nécessaires à la publication. L’adaptation des cartes à cette direction graphique sera travaillée ensuite avec l’utilisateur.
